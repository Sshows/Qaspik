# Qaspik (`@Qaspik_bot`) — Автодемпинг Kaspi (`-1 ₸`) & Модуль НКТ

Аналог `app.kaskyr.com` в формате **Telegram-бота (`@Qaspik_bot`) + Web-панели**.

## Основной функционал

1. **Вход в Kaspi Кабинет по номеру телефона и SMS (без запроса API-ключа):**
   - Клиент вводит свой номер телефона от кабинета продавца Kaspi и SMS-код.
   - Бот сам сохраняет сессию кабинета (`idmc.shop.kaspi.kz` / `mc.shop.kaspi.kz`), вытягивает БИН/ИИН ИП и список всех товаров.
2. **Подписка строго на ИП (`БИН/ИИН`):**
   - Подписка привязывается к конкретному ИП (`Merchant`), а не к отдельному аккаунту.
   - Повторный абуз бесплатного периода на один и тот же БИН заблокирован.
3. **Лимит в 3–4 устройства на 1 ИП:**
   - К одному ИП может быть подключено до **4 устройств / аккаунтов** (например, владелец + 3 менеджера по инвайт-коду ИП).
   - 5-е устройство автоматически блокируется до отключения одного из активных устройств.
4. **Автодемпинг 24/7 (`-1 ₸` без спроса хозяина):**
   - Пока у ИП активна подписка, бот автоматически проверяет цены конкурентов.
   - Если у нас цена `45 500 ₸`, а конкурент поставил `45 498 ₸`, бот **сам снижает цену до `45 497 ₸`** (не опускаясь ниже минимальной стоп-цены `minPrice`) и возвращает товар на **1-е место**.
5. **Модуль НКТ (`?context=nct&filterType=Published&orderBy=NctNotRegisteredFirst`):**
   - Сортировка опубликованных товаров так, чтобы первыми шли товары **без регистрации в НКТ (`NotRegistered`)**.
   - Автоматическая генерация и привязка 13-значных кодов **NTIN (`02...`)**.

## Запуск

1. Скопируйте `.env.example` в `.env` и укажите `TELEGRAM_BOT_TOKEN`:
   ```bash
   cp .env.example .env
   ```
2. Установите зависимости и запустите:
   ```bash
   npm install
   npm start
   ```
3. Откройте Telegram-бота **[@Qaspik_bot](https://t.me/Qaspik_bot)** и нажмите `/start`, либо откройте веб-панель:
   `http://localhost:3000/products?context=nct&filterType=Published&currentPage=1&orderBy=NctNotRegisteredFirst`
